# Documentación de QuotesFlow

Toda la documentación va en español (regla R11 de `PLAN.md`).

| Carpeta / archivo | Contenido | Regla |
|---|---|---|
| `audits/` | Informes de auditoría: línea base, seguridad de cada fase, rondas de dudas y auditoría | R10 |
| `security/` | Documentos de seguridad vivos: matriz de permisos, modelo de amenazas | R5, F1-T04 |
| `modulos/` | Un archivo por módulo funcional: propósito, reglas de negocio, endpoints y ejemplos | R12 |
| `guia-de-codigo.md` | Convenciones de idioma, nombres, comentarios y JSDoc | R11 a R13 |

Archivos de la raíz del repositorio que también son documentación:

- `CONTEXT.md`: lo que ya está hecho y confirmado (R3).
- `PLAN.md`: el trabajo pendiente, las reglas y las decisiones.
- `QUESTION.md`: dudas de los modelos (R14).
- `tests/README.md`: guía de los tests.
